#### Get Familiar Packages

- **[Redux Toolkit](https://redux-toolkit.js.org/tutorials/quick-start)**: State management tool
- **[React Query](https://react-query-v3.tanstack.com/overview)**: Potentially help the project save on bandwidth and increase memory performance
- **[Styled Component](https://styled-components.com/docs)**: Utilising tagged template literals and CSS - JS styling

## Project Setup

- create an _.env_ file in the project root, copy the keys in the _.env.sample_ file to _.env_ and request values from admin.
- run `yarn`
- run `yarn start`
